# 마케팅 활용동의 획득 실적 대시보드

한화손보 고객상담파트 · 임원보고용

`index.html` **파일 하나만** 있으면 됩니다. 더블클릭해서 브라우저로 열면 바로 실행되며,
서버·인터넷·외부 라이브러리가 전혀 필요 없습니다. (메일 첨부 / 사내망 공유 가능)

## 화면 구성

**대시보드 (기본 화면)**

1. 전체 동의 누적건수
2. 월별 시도건수 · 동의건수 · 동의율 (차트) — 막대=동의건수, 점선=동의율, 월 아래=시도건수
3. 9월부터 주간 실적
> 9월부터는 **동의건수만 추출**됩니다. 시도건수 · 동의율은 9월 화면에 표시되지 않으며,
> 상단 KPI의 시도 누계 · 평균 동의율은 **1~8월 기준**입니다.

4. 데이터 기준일 (우측 상단 · 하단 표시)
5. 인센티브 기준 (구간별 인원 현황 · 산정 방식)

**월 탭 (1~8월)** — 상단 월 탭 또는 **월별 차트의 막대**를 누르면 이동
해당 월의 **엑셀 원본 내용만** 표시합니다 : 시도건수 / 동의건수 / 동의율 +
상담사별 상세표(센터 · 팀 · 사번 · 상담사명 · 시도 · 동의 · 동의율, 검색 가능)

## 샘플 데이터 (테스트용)

현재 `sampleMode: false` (실제 화면)입니다. 9월 실적이 아직 없어 해당 영역은 입력 대기로 표시됩니다.
화면이 어떻게 채워지는지 미리 보려면 `sampleMode: true` 로 바꾸세요.

- 실제 실적을 입력한 뒤에는 파일 상단 `sampleMode: false` 로 변경하면 영구 해제
- 샘플은 `sampleSep` 블록에만 들어 있고, 실제 입력란(`sep`)은 그대로 보존됩니다

샘플 내용 (8월 실적 기반으로 생성한 가상 수치)

| 항목 | 값 |
|---|---|
| 참여 | 44명 / 명단 55명 |
| 동의건수 | 1,655건 (시도 11,712건 · 동의율 14.1%) |
| 인센티브 | 1,027,200원 · 달성 28명 |
| 구간 분포 | 1구간 18명 · 2구간 6명 · 3구간 4명 · 미달 16명 |
| 상한 적용 | 1명 (174건 → 174,000원이나 150,000원으로 조정) |

## 매주 직접 업데이트하기 (업무망 · 인터넷 불필요)

대시보드 맨 아래 오른쪽 **[주차 데이터 갱신]** 을 누르면 입력 화면이 열립니다.
인터넷 연결이 없어도 동작하며, 코드를 건드릴 필요가 없습니다.

1. 엑셀에서 **`실적 및 인센티브` 시트**를 열고 `Ctrl+A` → `Ctrl+C`
   → 화면의 **1번 칸**에 `Ctrl+V`
2. 엑셀에서 **`동의List` 시트**를 열고 `Ctrl+A` → `Ctrl+C`
   → 화면의 **2번 칸**에 `Ctrl+V`
3. **데이터 기준일** 확인 (비워두면 리스트의 마지막 날짜가 들어갑니다)
4. **[확인하기]** → 아래 세 가지가 모두 `✓` 인지 봅니다
   - 상담사별 동의합계 = 리스트 건수
   - 주차별 합계 = 리스트 건수
   - 상담사별 건수 전원 일치
5. **[새 index.html 저장]** → 내려받은 파일로 기존 `index.html` 을 덮어쓰면 끝

### 알아두실 점

- **시트를 통째로 복사해도 됩니다.** 머리글을 찾아 필요한 열만 읽으므로
  열 순서가 바뀌거나 옆에 다른 열이 있어도 괜찮습니다
- **주차별 실적은 따로 입력하지 않습니다.** 동의 리스트에서 자동으로 계산되므로
  주차 합계와 리스트 건수가 어긋날 수 없습니다
- 주차 기간(예: `9/01~9/04`)은 동의가 발생한 날짜에서 계산합니다.
  실제 운영 주차와 다르면 확인 화면에서 직접 고칠 수 있습니다
- **[미리보기 적용]** 은 지금 열린 화면만 바꿉니다. 파일을 실제로 갱신하려면
  반드시 **[새 index.html 저장]** 을 눌러야 합니다
- 숫자가 `✕` 로 나오면 원본 엑셀에 누락·중복이 있을 수 있습니다.
  이때는 저장 버튼이 나타나지 않습니다
- 인센티브 금액·구간별 인원은 **동의건수만 넣으면 자동 계산**됩니다

## 매주 업데이트 방법

`index.html`을 메모장·VS Code 등으로 열고 파일 위쪽의
`★★★ 데이터 입력 영역 ★★★` 블록만 수정한 뒤 저장 → 브라우저 새로고침(F5)

**① 데이터 기준일**

```js
baseDate : "2026-09-12",
updatedAt: "2026-09-12",
```

**② 주간 실적 — 매주 한 줄 추가**

```js
weeks: [
  { label:"1주차", range:"9/01~9/05", att:980,  agr:150 },
  { label:"2주차", range:"9/08~9/12", att:1200, agr:180 },   // ← 추가
],
```

**③ 상담사별 동의건수 — 맨 뒤 숫자만 수정**

```js
["청주","특화팀","8061853","강유진", 1, 34],
//  센터    팀      사번     상담사명  참여  동의건수
```

참여여부는 `1`=참여 / `0`=미참여. 참여자가 바뀌면 줄을 추가하거나 삭제하면 됩니다.

> 인센티브 금액, 구간별 인원, 1인 평균 금액은 **입력하지 않습니다.**
> 동의건수만 넣으면 전부 자동 계산됩니다.

## 인센티브 기준 (9월 자율참여~)

| 구간 | 기준 | 단가 |
|---|---|---|
| 1구간 | 20건 이상 | 전건 500원 |
| 2구간 | 50건 이상 | 전건 700원 |
| 3구간 | 100건 이상 | 전건 1,000원 |

- 구간 도달 시 **전 건수**에 해당 단가 적용 (예 : 53건 → 53 × 700원 = 37,100원)
- **1인 월 상한 150,000원** (예 : 286건 → 286,000원이나 상한 적용으로 150,000원)
- 목표 없음 (자율참여). 1~8월은 시도·동의건수 별도 시상으로 인센티브 미적용
- 기준이 바뀌면 `DATA.incentive`의 `tiers` / `cap` 값만 수정

## 데이터 출처

`3~8월 마케팅 활용동의 실적` 엑셀의 월별 시트에서 추출했습니다.

- 1~8월 누계 : 시도 61,471건 / 동의 11,435건 (엑셀 집계표와 일치)
- 1~2월은 시범 운영으로 상담사별 상세가 없어 전체 집계만 표시
- 6월은 대구센터 자체 진행분(시도 551 / 동의 47) 포함. 엑셀 자체에서 월 집계표(동의 2,160)와
  상담사별 합계(2,159)가 1건 차이나며, 월 탭 하단에 각주로 표기됨
- 인센티브 로직은 엑셀 `6월 simu` 시트 결과(총 1,224,000원 / 달성 33명)와 동일하게 검증
