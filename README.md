# 마케팅 활용동의 획득 실적 대시보드

한화손보 고객상담파트 · 임원보고용

`index.html` **파일 하나만** 있으면 됩니다. 더블클릭해서 브라우저로 열면 바로 실행되며,
서버·인터넷·외부 라이브러리가 전혀 필요 없습니다. (메일 첨부 / 사내망 공유 가능)

## 화면 구성

**대시보드 (기본 화면)**

1. 전체 동의 누적건수
2. 월별 시도건수 · 동의건수 · 동의율 (차트) — 막대=동의건수, 점선=동의율, 월 아래=시도건수
3. 9월부터 주간 실적
4. 9월 센터별 실적 (동의건수 · 인센티브 · 1인 평균 금액)
5. 상담원 Ranking (9월 동의건수 · 인센티브)
6. 데이터 기준일 (우측 상단 · 하단 표시)
7. 인센티브 기준

**월 탭 (1~8월)** — 상단 월 탭 또는 **월별 차트의 막대**를 누르면 이동
해당 월의 **엑셀 원본 내용만** 표시합니다 : 시도건수 / 동의건수 / 동의율 +
상담사별 상세표(센터 · 팀 · 사번 · 상담사명 · 시도 · 동의 · 동의율, 검색 가능)

## 샘플 데이터 (테스트용)

현재 `sampleMode: false` (실제 화면)입니다. 9월 실적이 아직 없어 해당 영역은 입력 대기로 표시됩니다.
화면이 어떻게 채워지는지 미리 보려면 우상단 **[샘플]** 버튼을 누르거나 `sampleMode: true` 로 바꾸세요.

- 화면 우상단 **[샘플 ON]** 버튼 → 실제 데이터 화면과 즉시 전환 (파일 수정 없이 확인용)
- 실제 실적을 입력한 뒤에는 파일 상단 `sampleMode: false` 로 변경하면 영구 해제
- 샘플은 `sampleSep` 블록에만 들어 있고, 실제 입력란(`sep`)은 그대로 보존됩니다

|---|---|

## 매주 업데이트 방법

`index.html`을 메모장·VS Code 등으로 열고 파일 위쪽의
`★★★ 데이터 입력 영역 ★★★` 블록만 수정한 뒤 저장 → 브라우저 새로고침(F5)

**① 데이터 기준일**

```js
baseDate : "2026-09-12",
updatedAt: "2026-09-12",
```

**② 주간 실적 — 매주 한 줄 추가**

```js
weeks: [
  { label:"1주차", range:"9/01~9/05", att:980,  agr:150 },
  { label:"2주차", range:"9/08~9/12", att:1200, agr:180 },   // ← 추가
],
```

**③ 상담사별 동의건수 — 맨 뒤 숫자만 수정**

```js
["청주","특화팀","8061853","강유진", 1, 34],
//  센터    팀      사번     상담사명  참여  동의건수
```

참여여부는 `1`=참여 / `0`=미참여. 참여자가 바뀌면 줄을 추가하거나 삭제하면 됩니다.

> 인센티브 금액, 구간별 인원, 센터별 실적, 1인 평균 금액, 랭킹은 **입력하지 않습니다.**
> 동의건수만 넣으면 전부 자동 계산됩니다.

## 인센티브 기준 (9월 자율참여~)

| 구간 | 기준 | 단가 |
|---|---|---|
| 1구간 | 20건 이상 | 전건 500원 |
| 2구간 | 50건 이상 | 전건 700원 |
| 3구간 | 100건 이상 | 전건 1,000원 |

- 구간 도달 시 **전 건수**에 해당 단가 적용 (예 : 53건 → 53 × 700원 = 37,100원)
- **1인 월 상한 150,000원** (예 : 286건 → 286,000원이나 상한 적용으로 150,000원)
- 목표 없음 (자율참여). 1~8월은 시도·동의건수 관리 기간으로 인센티브 미적용
- 기준이 바뀌면 `DATA.incentive`의 `tiers` / `cap` 값만 수정
