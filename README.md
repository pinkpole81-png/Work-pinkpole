# 마케팅 활용동의 획득 실적 대시보드

한화손해보험 고객센터 운영팀 · 임원보고용 대시보드

`index.html` **파일 하나만** 있으면 됩니다. 더블클릭하여 브라우저로 열면 바로 실행되며,
서버·인터넷 연결·외부 라이브러리가 전혀 필요하지 않습니다. (메일 첨부 / 사내망 공유 가능)

## 구성

| 탭 | 내용 |
|---|---|
| 전체 누적 | 1~8월 누적 KPI, 월별 동의 그래프(동의율 추이), 월별 요약표, 채널별 구성, 센터·팀별 누적, 상담원 누적 Ranking |
| 1월 ~ 8월 | 해당 월 KPI, 센터별·팀별 실적, 상담원 Ranking(검색 가능), 채널별 구성 |
| 9월 자율참여 | 참여 현황, 주간 실적, 인센티브 구간별 인원, 센터별 인센티브·평균 금액, 상담원별 인센티브 |

- **1~8월** : 시도 / 동의건수 관리 기간 (목표 대비 관리, 인센티브 없음)
- **9월부터** : 목표 없이 자율참여, 획득 건수에 따른 인센티브만 산정 — 완전히 별도 체계

## 매주 업데이트 방법

`index.html`을 메모장·VS Code 등으로 열고, 파일 중간의
`★★★ 데이터 입력 영역 ★★★` 블록만 수정하면 모든 수치와 그래프가 자동으로 다시 계산됩니다.

1. **데이터 기준일** — `DATA.meta.baseDate`, `updatedAt` 수정
2. **주간 실적** — `DATA.sep.weeks` 에 한 줄 추가
   ```js
   { label:"2주차", range:"9/08~9/12", att:1200, agr:180 },
   ```
3. **참여자별 동의건수** — `DATA.sep.roster` 의 각 줄 마지막 숫자(동의건수)와
   참여여부(1=참여 / 0=미참여)를 수정
   ```js
   ["청주","특화팀","8061853","강유진", 1, 34],
   //  센터    팀      사번     상담사명  참여 동의건수
   ```
4. 저장 후 브라우저에서 새로고침 (F5)

> 인센티브 금액, 구간별 인원, 센터별 평균 금액, 랭킹, H-POINT는 **입력하지 않습니다.**
> 동의건수만 넣으면 전부 자동 계산됩니다.

## 인센티브 산정 기준 (9월~)

| 구간 | 기준 | 단가 | 비고 |
|---|---|---|---|
| 1구간 | 20건 이상 | 전건 500원 | H-POINT 1,000점 |
| 2구간 | 50건 이상 | 전건 700원 | H-POINT 1,000점 |
| 3구간 | 100건 이상 | 전건 1,000원 | H-POINT 1,000점 |

- 구간 도달 시 **전 건수**에 해당 단가 적용 (예: 53건 → 53 × 700원 = 37,100원)
- 1인 월 지급 상한 **150,000원**
- 기준 변경 시 `DATA.incentive` 의 `tiers` / `cap` 값만 수정
